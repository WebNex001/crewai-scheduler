```bash

sudo systemctl start taskflow

# 停止服务
sudo systemctl stop taskflow

# 重启服务
sudo systemctl restart taskflow

# 查看服务状态
sudo systemctl status taskflow

# 查看日志
journalctl -u taskflow -f
```

**(2) 备份与恢复**

```bash

cp /opt/taskflow/instance/taskflow.db /backup/taskflow_$(date +%Y%m%d).db

tar -czvf taskflow_backup_$(date +%Y%m%d).tar.gz /opt/taskflow/instance/
```

## 四、已知限制和后续建议

### 4.1 已知限制

| 限制项 | 严重程度 | 说明 | 规避方案 |
|-------|---------|------|---------|
| SQLite 并发写入 | 中 | 不支持高并发写入场景 | 预计用户量 < 1000 可正常使用 |
| 定时任务单节点 | 低 | 提醒功能仅支持单实例部署 | 初期使用单机部署即可满足 |
| 前端无 CDN | 低 | 静态资源加载速度依赖服务器 | 后期可接入 CDN 加速 |
| 无数据导出功能 | 中 | 不支持任务数据导出 | 建议手动备份数据库 |
| 验证码功能缺失 | 中 | 无图形验证码保护 | 已实现登录失败锁定机制 |

### 4.2 后续优化建议

**(1) 高优先级 (建议 1-3 个月内完成)**

- [ ] **引入 Redis 缓存**：提升频繁访问数据的读取性能
- [ ] **添加数据导出**：支持 CSV/Excel 格式导出任务
- [ ] **完善错误处理**：统一异常处理和用户友好的错误提示

**(2) 中优先级 (建议 3-6 个月内完成)**

- [ ] **迁移至 PostgreSQL**：支持更大数据量和并发访问
- [ ] **添加邮件通知**：支持邮件发送任务提醒
- [ ] **移动端适配**：优化移动端浏览体验

**(3) 低优先级 (建议 6-12 个月内完成)**

- [ ] **引入 Celery**：支持异步任务处理和定时任务
- [ ] **添加 API 文档**：使用 Swagger 生成 API 文档
- [ ] **多语言支持**：国际化(i18n)准备
- [ ] **日志分析平台**：接入 ELK 进行日志分析

### 4.3 技术债务

| 债务项 | 影响范围 | 修复建议 |
|-------|---------|---------|
| 前端未分离 | 维护性 | 后期可拆分为独立前端项目(Vue/React) |
| 硬编码配置 | 可扩展性 | 逐步迁移至配置中心 |
| 单元测试覆盖不足 | 可靠性 | 逐步补充单元测试，目标覆盖率 > 70% |
